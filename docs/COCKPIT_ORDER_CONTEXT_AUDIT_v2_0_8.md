# Cockpit-Reihenfolge, Rechtsklick und Zahltags-Workflow – Audit v2.0.8

## Umsetzung

- Cockpit gestalten ist jetzt ein Dialog, nicht nur ein Ein-/Ausblend-Menü.
- Cockpit-Bereiche können per Hoch/Runter sortiert werden.
- Sichtbarkeit und Reihenfolge werden in den Settings gespeichert.
- Rechtsklick auf freie Reiterflächen zeigt die aktuell gültigen Aktionen aus dem Menü Bearbeiten.
- Sparziele-Tab hat ein eigenes Rechtsklick-Menü für Neu/Bearbeiten/Löschen bzw. Verwaltung.
- Hilfe erklärt den Unterschied zwischen Kalender-Monat und Finanz-/Zahltags-Monat.

## Entscheidung Zahltag

Bei Zahltag am 25. ist das Geld praktisch für den Folgezeitraum gedacht. Die App bleibt in v2.0.8 aber kalenderbasiert. Eine echte Periode 25.–24. sollte als eigenes Feature umgesetzt werden, damit Cockpit, Budget-Ampel, Fixkosten, Exporte und Auswertungen konsistent bleiben.
